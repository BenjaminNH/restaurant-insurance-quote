# 餐饮保险报价器 MVP 开发与验收说明

## 1. 交付范围

本次交付为移动端优先的静态前端 MVP，支持单一门店报价，覆盖公众责任险、食品安全责任险和雇主责任险。页面按照所选险种动态组成 3 至 5 个步骤，不选择的险种不会出现对应配置页面。

MVP 不保存客户留资，不接入数据库、管理后台或正式核保系统。员工信息仍以页面内岗位人数录入为主，但岗位、费率和显示文案已集中配置，后续可扩展为员工级配置，不需要复制页面。

## 2. 已实现能力

- 门店经营面积输入和三类险种多选；
- 公众责任险、食品安全责任险方案选择；
- 雇主责任险档位、岗位人数和员工年龄范围输入；
- 按规则版本 `mvp-1.1` 计算并展示保费明细；
- 正常报价、不承保、人工报价和部分报价四类结果；
- 单一门店会话草稿恢复，草稿保存规则版本并设置 7 天有效期；
- 食品安全责任险承保资料展示“食品生产许可证”；
- 销售联系入口和后续客户留资扩展位置；
- Next.js 静态导出，产物位于 `out/`。

## 3. 关键业务口径

- 雇主责任险总人数少于 8 人时不承保，不转人工报价；
- 员工年龄存在 16 至 65 周岁范围外情况时转人工报价；
- 面积超过自动报价范围时以规则为准；若其他险种可计算，则只展示已知保费小计，不展示最终总价；
- 报价结果保留规则版本，后续服务端保存报价时必须按输入和规则版本重新计算；
- 当前只报价一个门店，不支持多门店汇总。

## 4. 代码结构

- `src/config/quote-rules.ts`：版本化报价规则；
- `src/features/quote/calculator/`：与界面解耦的纯 TypeScript 计算模块；
- `src/features/quote/schemas/`：规则和报价输入校验；
- `src/features/quote/state/`：动态步骤和会话草稿；
- `src/features/quote/components/`：报价向导、步骤组件和结果状态；
- `tests/unit/`：规则、边界、计算、步骤和草稿单元测试；
- `tests/e2e/`：Chromium 与 WebKit 移动端流程验收。

## 5. 验收命令

```bash
pnpm check
pnpm test:e2e
```

当前验收基线：

- ESLint 通过；
- TypeScript 类型检查通过；
- 48 个单元测试通过；
- 20 个移动端端到端测试通过，覆盖 Chromium 和 WebKit；
- Next.js 生产构建及静态导出成功；
- `out/index.html` 可由普通静态文件服务器访问。

## 6. 后续阶段建议

1. 接入客户留资和销售分配，同时由服务端重新计算报价；
2. 将员工信息扩展为可配置的员工明细，并保留岗位费率映射；
3. 增加数据库、报价记录和管理后台；
4. 在正式上线前补充真实销售联系方式、隐私说明和正式核保衔接流程。
