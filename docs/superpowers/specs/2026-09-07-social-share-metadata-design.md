# 社交分享元数据设计

## 目标

为餐饮安心保报价器补齐静态社交分享信息，提高链接在微信及其他支持 Open Graph 的平台中显示网站名称、标题、摘要和封面图的概率，同时保持当前纯静态导出和托管商可移植性。

## 实现范围

- 页面标题使用“餐饮安心保｜餐饮门店责任险保费智能预估”。
- 网站名称使用“餐饮安心保”。
- 页面及分享摘要使用“快速预估公众责任险、食品安全责任险和雇主责任险保费”。
- 规范网址指向当前生产地址 `https://restaurant-insurance-quote.netlify.app/`。
- 输出完整的 Open Graph 网站元数据，包括标题、网站名称、摘要、网址、类型、语言和分享图片信息。
- 输出通用 Twitter Card 元数据，作为其他聊天软件和社交平台的兼容补充。
- 添加静态站点图标、Apple Touch 图标和 1200×630 分享封面图。

## 素材设计

分享封面沿用现有页面的蓝绿色视觉体系，内容保持简洁：品牌名称、产品用途和三类责任险范围。重要文字置于画面中央安全区域，以适应微信可能采用的缩略和裁切方式。

## 技术约束

- 使用 Next.js 16 App Router 的静态 Metadata 与文件约定。
- 所有元数据在构建时写入 HTML，不依赖客户端脚本。
- 图片作为静态构建产物发布，不使用图片优化服务或托管商专属功能。
- 本次不接入微信 JS-SDK，不新增服务端签名接口，也不承诺微信一定将粘贴的 URL 转换为卡片。

## 验证

- 自动测试校验 Metadata 对象中的关键字段和值。
- 静态构建后检查首页 HTML 包含规范网址、Open Graph、Twitter Card 和图标标签。
- 检查分享图片与图标出现在 `out` 构建产物中并可通过 HTTPS 访问。
- 保持现有 lint、类型检查、单元测试和静态构建全部通过。
