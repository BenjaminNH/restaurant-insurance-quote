# 餐饮保险智能报价器

一个面向餐饮企业客户的移动端保险保费预估工具。用户可以选择公众责任险、食品安全责任险和雇主责任险方案，填写单一门店及员工人数信息，快速获得标准规则下的预估保费。

当前项目为可独立运行的 MVP 静态前端，重点验证移动端报价流程、规则计算和异常报价状态。

## 核心功能

- 三类险种可独立选择，也可组合报价。
- 公众责任险和食品安全责任险根据经营面积自动匹配保费系数。
- 雇主责任险根据保障方案、岗位人数和最低 8 人承保门槛计算。
- 支持正常报价、部分报价、人工报价和不符合承保条件等结果状态。
- 展示责任限额、免赔条件、投保资料和对应的处理提示。
- 使用会话草稿保存填写进度，刷新页面后可继续操作。
- 针对移动端输入、软键盘遮挡、底部安全区域和触摸操作进行了适配。

## 技术栈

- Next.js App Router、React、TypeScript
- Tailwind CSS
- React Hook Form、Zod
- Vitest、Playwright

报价引擎采用与 UI 解耦的纯 TypeScript 模块，规则数据按版本管理。项目使用 Next.js 静态导出，不依赖特定托管商的服务端运行时。

## 本地运行

```bash
npm install
npm run dev
```

开发服务器默认运行在 `http://localhost:3000`。

## 测试与静态构建

运行 lint、类型检查、单元测试和静态构建：

```bash
npm run check
```

运行端到端测试：

```bash
npm run test:e2e
```

静态构建产物生成在 `out/` 目录，可部署到支持静态文件的网站托管服务。

## 业务规则与免责声明

当前报价规则版本为 `mvp-1.1`：

- [保费规则说明](docs/餐饮保险报价器-保费规则梳理.md)
- [结构化规则配置](docs/餐饮保险报价器-MVP规则.json)

本项目仅用于咨询阶段的保费预估，不替代保险核心系统、正式核保或正式出单。最终承保范围、保费及条款以保险公司审核和正式保单为准。

## 当前限制

- MVP 仅支持单一门店报价，不处理多门店合并报价。
- 员工年龄条件在正式投保时核验，当前页面不采集员工年龄明细。
- 尚未接入客户留资、数据库、员工个性化配置或管理后台。
- 报价计算在浏览器端完成；未来保存报价时需要由服务端按输入和规则版本重新计算。
- 结果页显示的业务手机号为演示号码，不能作为正式咨询渠道。
