# 餐饮保险智能报价器

## 项目背景

本项目面向餐饮企业客户，建设一套保险保费预估工具。客户可根据自身实际情况填写门店经营面积、选择保险方案，并录入员工岗位和年龄等信息；系统依据已确认的标准规则，快速输出公众责任险、食品安全责任险及雇主责任险的预估保费与保障信息。

报价器的目标是让客户在咨询早期就能理解可选保障方案、影响保费的主要因素及预计费用，同时帮助销售人员统一报价口径、减少手工计算。雇主责任险总人数不足 8 人时不承保；超面积门店、员工年龄不符合要求或岗位未覆盖等超出标准规则的情况不输出确定价格，并明确提示“需人工报价/承保确认”。

## 当前范围

第一阶段以“标准方案预估报价”为主，覆盖：

- 公众责任险：按门店、方案和经营面积系数预估保费；
- 食品安全责任险：按门店、方案和经营面积系数预估保费；
- 雇主责任险：按版本、员工岗位和人数预估年保费，并校验标准承保人数与年龄范围；
- 展示责任限额、免赔条件、所需承保资料及人工处理提示。

本项目不替代保险核心系统、正式核保或正式出单。报价结果仅为预估，最终承保范围、保费及条款以保险公司审核和正式保单为准。

## 规则依据与当前状态

保费规则基于已确认的餐饮保险业务资料整理，相关文件位于 `docs/`：

- [`餐饮保险报价器-保费规则梳理.md`](docs/餐饮保险报价器-保费规则梳理.md)：供业务、产品及承保人员核对的规则说明；
- [`餐饮保险报价器-MVP规则.json`](docs/餐饮保险报价器-MVP规则.json)：供后续前后端开发读取的结构化规则配置。

当前 MVP 已完成可独立运行的静态前端，包含动态五步报价流程、版本化规则计算、会话草稿恢复、部分报价、不承保和人工报价状态。规则版本为 `mvp-1.1`。报价结果仍仅用于保费预估，不能替代正式核保或出单。

## 本地运行

```bash
pnpm install
pnpm dev
```

开发检查与静态导出：

```bash
pnpm check
pnpm test:e2e
```

`pnpm check` 通过后，静态站点生成在 `out/` 目录，可部署到任意支持静态文件的网站托管服务。
